# Enjoy CMake

Это небольшое задание, в рамках которого предлагается собрать и запустить данный проект. Разрешается редактировать файлы, исправляя ошибки, но не изменяя логику и смысл.

В процессе запуска CMake у Вас могут возникать разные вопросы. Ответом на один из них может являться строчка:

```
sudo apt install libgtk-4-dev
```
